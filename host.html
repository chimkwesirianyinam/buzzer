        Session

        Signing out leaves this room. Contestants in it can keep buzzing until the room expires, but you will need a new room to run another competition.

        Host password

        To protect the host console, open your Render dashboard, go to Environment, add a variable named HOST_PASSWORD with the password you want, and save. The app restarts and asks for it before anyone can host. Contestants never need it.

        Running a round

        1. Open Schools & Teams, add each school with its logo and press Save setup.
        2. Show the room code (or open the Display Screen) so each student can join from their phone.
        3. Ask the question, then press Open buzzers in the Live Console.
        4. The first student to buzz counts for their school. Their name and logo appear here and on the display.
        5. Press Award a point, then Open buzzers again for the next question.
